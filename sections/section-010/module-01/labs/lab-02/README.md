# Reshape A Request Sandbox

Welcome to the Module 1 second practice sandbox. Lab 1 was about *choosing a destination*. This one is about everything else a matched rule can do to a request on its way there: answer it with a redirect, rewrite its path, stamp and strip headers, and satisfy a browser's CORS preflight — without the application changing.

## Launching the Lab
Run the following command in your terminal to boot the kind Kubernetes cluster:
```bash
astrona run --git git@github.com:astrona-io/ATS014.git -c sections/section-010/module-01/labs/lab-02
```
