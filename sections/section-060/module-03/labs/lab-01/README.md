# Ingress With The Kubernetes Gateway API Sandbox

Welcome aboard, astronaut. This is the Module 3 training mission. You'll create a Gateway that brings its own proxy with it, then let a route from a *different* namespace (another planet) attach to it. This API denies that by default.

## Launching the Lab
Run the following command in your terminal to boot the kind Kubernetes cluster:
```bash
astrona run --git git@github.com:astrona-io/ATS014.git -c sections/section-060/module-03/labs/lab-01
```
