# Shift Traffic With Weighted Routing Sandbox

Welcome to the Module 1 targeted practice sandbox, astronaut. Your mission: launch a new ship class without risking the fleet. In this lab you'll run a canary split with weighted destinations, pin internal testers to the new version with a rule above the weights, and prove the split is real by measuring it over enough requests to mean something.

## Launching the Lab
Run the following command in your terminal to boot the kind Kubernetes cluster:
```bash
astrona run --git git@github.com:astrona-io/ATS014.git -c sections/section-020/module-01/labs/lab-01
```
